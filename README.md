# Windstorm Repo Minions

**Your own computers do your repo's chores.**

Every time you save a change to a project on GitHub, GitHub can run chores for it: tests, builds, checks. Those
chores can run on GitHub's machines or on computers you own. This skill is for the second way: it will set up a
computer of yours to do the chores for your private repositories, keep it ready, and teach your coding agent to
use it.

## Status: not released

Nothing here can be installed yet. This skill is built in the open, in this order:

1. The plan, `DNA-STRAND-MASTER-PLAN.md`: every claim the skill makes, each with the test that proves it.
2. The code.
3. Tests on real machines that have none of our set-up, before any release.

## One rule already

A computer of yours should do chores only for **private** repositories. On a public repository a stranger's pull
request could run code on that computer. GitHub says the same in its own documentation.
